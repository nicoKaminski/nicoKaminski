## 🎯 Sobre mí

Soy Técnico Universitario en Desarrollo de Software, con foco principal en el desarrollo frontend con **React y TypeScript**, orientado a crear interfaces claras, escalables y pensadas para las personas que las usan.

Trabajo también en backend con tecnologías como **Node.js, Express, Java y Spring Boot**, además de bases de datos relacionales como **PostgreSQL, MariaDB y MySQL**, lo que me permite participar en el ciclo completo de una aplicación y trabajar sobre integración, lógica, validaciones y datos cuando el producto lo necesita.

Mi experiencia en **UX/UI** complementa el desarrollo técnico y me ayuda a pensar cada solución más allá del código, buscando que arquitectura, funcionalidad y experiencia de usuario trabajen juntas.

## 🧭 Cómo trabajo

Primero busco entender bien el problema, discutir alternativas y elegir la solución que mejor se adapta al contexto. A partir de ahí defino el alcance, el orden de implementación y los criterios con los que voy a evaluar el resultado.

La **IA forma parte de mi proceso como herramienta de apoyo** para investigar, analizar alternativas, planificar y revisar soluciones, manteniendo las decisiones y la validación final bajo mi criterio.

**Diseño → Debate → IA asistida → Implementación → Revisión → Validación**
